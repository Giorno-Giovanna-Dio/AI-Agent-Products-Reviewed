# Cell 洞察筆記（網頁閱讀）

**所有** Cell 洞察筆記都可以用這個站點閱讀：左側選單選產品，或直接用
`#/reviews/<slug>.md`（例如 `#/reviews/emdash.md`）。

不必在 IDE 開 `reviews/*.md` 當主要閱讀方式。

- 結構化 catalog：[`cells.yaml`](https://github.com/Giorno-Giovanna-Dio/AI-Agent-Products-Reviewed/blob/main/cells.yaml)
- 原始 Markdown 在 GitHub；此站由 GitHub Actions 自 `main` 同步 `reviews/` 後部署。
